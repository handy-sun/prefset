## how to use colorfull file

SecureCRT -> Options -> Global Options

General -> Configuration Paths -> Configuration folder -> Configuration data is
stored in location below.
Press `...` button, then show explorer at `Roaming\VanDyke\Config`, enter `Keywords` directory

General -> Default Session -> Edit Default Settings

Terminal -> Keyword Highlighting -> List name:  choose your color name, Advanced
-> Highlight style -> Color

Will popup dialog : Apply default session changes, choose `Change All sessions
(no undo)`
